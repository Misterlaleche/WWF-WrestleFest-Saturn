# Evidencia06

Cuatro pasadas finales del mismo programa: final-none(TAG), final-1m(TAG),
final-4m(ROYAL/Crush) y final-corrupt(rechazo esperado del atlas).
El BIN/CUE bueno es idéntico en los tres primeros; el cuarto cambia sólo un
byte de FRONT.TEX y EDC/ECC. Cada informe congela hash del harness, identidad
del emulador/BIOS/programa y configuración. Sólo mandos, observación sin escritura.

Comparaciones estáticas: roster None/1MiB, Crush4MiB y confirmación4MiB;
cero diferencias en70335/70335/70335/76479 píxeles de fondo respectivamente.

ciclo de color$5EAE:2405 diferencias temporales. Se conserva en los archivos
externos, no se usa como validación ni se oculta rebajando tolerancias.
