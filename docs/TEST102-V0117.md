# Test102 / V0.117 — original two-button manual TAG path

Test100 hardware feedback reported manual tagging as effectively unavailable. The native engine already had a hidden Saturn-C tag edge, but the 1991 cabinet has only two action buttons and therefore Arcade Mode must not depend on a third button.

External control evidence is consistent: WrestleFest cabinet documentation lists only Punch/Kick, and long-standing player/move-guide documentation describes a normal tag at the partner corner with Kick; the same guide also documents P or K as tag inputs in the headlock double-team context.

The live TAG loop now accepts a fresh **Kick** edge at the player partner corner as the standard manual tag. Saturn C remains an optional convenience alias. A KO reserve cannot be tagged in. Current native corner coordinates are still explicitly provisional because the raw-to-Saturn coordinate transform is not yet proven.

`tools/test_manual_tag.c` validates Kick-tag, KO-reserve rejection, and the retained C alias.

The special headlock-tag double-team is **registered but not implemented by this checkpoint**; it must not be confused with the standard legal-wrestler swap.
