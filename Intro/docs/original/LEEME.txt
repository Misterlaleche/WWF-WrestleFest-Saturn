WWF WRESTLEFEST — WP0 R04 — SEGA SATURN NTSC
Revisión independiente de preparación, audio y temporizador. 29/10/2026.

PARA PROBAR EN SATURN CON MODE

Descomprime el paquete y copia juntos WF-WP0-R04.bin y WF-WP0-R04.cue a
una carpeta nueva de MODE. Selecciona esa imagen. No mezcles el CUE con
un BIN anterior ni renombres solo uno de los dos archivos.
No requiere cartucho de expansión RAM. Esta entrega corresponde a NTSC;
la cadencia no está adaptada a PAL.

Tras la carga oculta se reproduce la escena desde la pantalla antidroga
hasta el título desarrollado. Al terminar permanece el último estado.
Start reinicia al final; A+B+C+Start reinicia durante la reproducción.
El reinicio incluye un breve periodo oculto de preparación.

QUÉ CORRIGE ESTA REVISIÓN

La última foto física de R03 muestra CODE 401, FRAME 614 y AUDIO 0.
En ese punto coinciden una actualización gráfica grande y la reposición
de audio. La auditoría ha revisado también las transiciones equivalentes
y los campos posteriores con 196 sprites.

1. Se conservan seis paquetes gráficos grandes en RAM de trabajo durante
   la carga oculta. Ocupan 106.072 bytes dentro del buffer de 131.072 que
   ya usaba el cargador. Durante la escena se evita leer esos paquetes
   desde la VRAM de VDP1. Sus bytes siguen siendo los originales.
2. El decodificador Rice consume menos CPU en SH-2. El archivo comprimido,
   las muestras, el evento de inicio y el reproductor SCSP no se alteran.
   La reconstrucción completa sigue siendo exacta, sin pérdida.
3. Las lecturas del temporizador FRT quedan protegidas frente a una
   interrupción entre sus dos bytes. La lectura anterior podía mezclar
   dos capturas. CPU 65401 era un máximo histórico, no una medición fiable
   atribuible por sí sola al fotograma 614. Este defecto del diagnóstico
   es independiente del control que produce el error 401.

No se amplía el plazo del campo, no se omiten estados ni se reduce el
contenido gráfico. La prueba con una demora provocada en 614 sigue
activando 401. Ese parche de prueba no forma parte de este BIN.
